# Student Registration App

Aplikasi desktop **Student Registration App** menggunakan Windows Presentation Foundation (WPF). Aplikasi ini menerapkan fitur CRUD.

## Fitur Utama

* **Simpan (Create):** Menambahkan data mahasiswa baru ke dalam daftar.
* **Tampil (Read):** Menampilkan seluruh data mahasiswa yang tersimpan ke dalam tabel/DataGrid secara *real-time*.
* **Edit (Update):** Memperbarui informasi data mahasiswa yang sudah ada dengan memilih baris data pada tabel.
* **Hapus (Delete):** Menghapus data mahasiswa tertentu dari daftar.
* **Cari (Search):** Memfilter dan mencari data mahasiswa berdasarkan kata kunci tertentu (misalnya berdasarkan Nama atau NRP).
* **Reset (Clear):** Mengosongkan seluruh kolom *input form* dan mengembalikan status form ke kondisi awal.

---

## Teknologi yang Digunakan

* **Framework:** .NET / Windows Presentation Foundation (WPF)
* **Bahasa Pemrograman:** C# & XAML
* **Penyimpanan Data:** *In-Memory Collection* (seperti `ObservableCollection<T>` atau `List<T>`)
* **IDE:** Visual Studio
